# The Art of Being Together · Lombok Guidebook

Mobile guidebook for the 15th anniversary journey of GKR Bendara & KPH Yudanegara, Lombok, 16–19 October 2026.
Prepared by Werkudara Group with Takshaka Event & Experience.

## Files
- `index.html`: the guidebook. All text and data (flights, hotel, itinerary, contacts) live in the `GUIDE` and `DAYS` blocks near the top of the script.
- `assets/images/`: cover photo, Takshaka logo, photos of Raja, Bulqis and Rama, and the Somewhere Lombok gallery (`hotel-*.webp`).
- `assets/docs/lombok-guidebook-backup.pdf`: PDF backup.
- `assets/docs/e-ticket-GJXCYI.pdf`: flight e-ticket, linked from the View E-Ticket buttons (`eticket` in `GUIDE.flights`).
- `robots.txt`: keeps the page out of search engines.

## Publish with GitHub Pages
Settings → Pages → Branch: `main`, folder `/ (root)` → Save. The link appears after 1–2 minutes.

## Privacy
GitHub Pages is public: anyone with the link can open the e-ticket and see the booking reference.
Share the link only with the guests and their team.
